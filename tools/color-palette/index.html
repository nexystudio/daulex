Generador de paletas

Genera combinaciones de cinco colores y copia cada código HEX.

Haz clic en un color para copiar su código.

¿Para qué sirve?

Es útil para buscar ideas de color al diseñar interfaces, páginas web o proyectos gráficos. Cada paleta tiene cinco colores con su código hexadecimal, listos para copiar.
