¿Para qué sirve?
Un JSON Formatter ayuda a leer y revisar configuraciones, respuestas de API y estructuras de datos. Esta herramienta valida la sintaxis, aplica sangría de dos espacios o elimina los espacios sobrantes, y todo ocurre en tu navegador.
